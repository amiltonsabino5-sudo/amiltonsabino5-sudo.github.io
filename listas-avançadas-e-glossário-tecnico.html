Seção 2 — Ranking de tecnologias

Ranking das 5 tecnologias web mais relevantes:

  1. HTML

    A espinha dorsal da web, fundamental para estruturar e dar significado semântico ao conteúdo.

  2. CSS

    Essencial para o design responsivo, estilização e adaptação de interfaces em diferentes telas.

  3. JavaScript

    Linguagem de programação que permite adicionar interatividade, dinamismo e lógica às páginas.

  4. DOM

    Interface de programação que representa a estrutura do documento para ser manipulada por scripts.

  5. HTTP

    O protocolo fundamental de comunicação que permite a transferência de dados na World Wide Web.

Seção 3 — Glossário de termos técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas na web.
CSS
Linguagem de estilos usada para descrever a apresentação visual de um documento.
JavaScript
Linguagem de script que permite a criação de conteúdos dinâmicos e controle de elementos.
Possui suporte tanto para execução no navegador quanto no servidor (via Node.js).
DOM (Document Object Model)
Árvore de Documentos
Representação estruturada em forma de objetos que o navegador utiliza para interagir com a página.
API
Interface de Programação de Aplicações
Conjunto de rotinas e padrões estabelecidos por um software para que outros aplicativos possam utilizar suas funcionalidades.
URL
Localizador Uniforme de Recursos, o endereço web utilizado para acessar páginas e arquivos.
DNS
Sistema de Nomes de Domínio que traduz endereços web legíveis em endereços de IP numéricos.
